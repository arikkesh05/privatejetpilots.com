## Key Architectural Decisions
- `packages/tokens/src/index.ts` is the single source of truth for the Aero Obsidian palette, using Node16 ESM exports (`./colors.js`).
- Audio is restricted to user-interaction-only tactile feedback using Web Audio API synthesis. No loops, no ambient bed, no automated chirps.
- Canvas background is locked to `#0A0A0A` (charcoal-black) with zero scanlines, global opacity degradation, or ambient animation.
- Motion is user-initiated or scroll-linked only. Perpetual ornament animations (nav border pulse, equalizer fallback loop, pitch-ladder drift) were deleted from `index.css` outright.
- `useSmoothScroll` owns Lenis and drives it from the GSAP ticker; `lenis.on('scroll', ScrollTrigger.update)` keeps triggered work locked to the smoothed position.
- `useScrollReveals` animates every `[data-reveal]` node once via `gsap.context()`, so React StrictMode remounts cannot orphan triggers. Reduced-motion operators never enter the hook and see the deck fully composed.
- Tone of record is civil-aviation authority: FL450, MACH 0.925, cabin altitude, Ka-band SATCOM. Military/gamer tokens (DEFCON, weapons-grade, dramatic squawk, radar lock) are retired.
- **The palette is fixed at the token layer, not per component.** The MDC tone ramps in `apps/docs/tailwind.config.js` were retokened so `primary`/`secondary` resolve to champagne (`#E0CCA0` / `#CBB079`), `tertiary` to platinum, and surfaces to the `#0A0A0A`→`#2E2D2C` obsidian step. A component that still spells a tone name therefore renders editorial rather than gamer. The saturated `gold` / `lilac` / `indigo` shorthand aliases stay in the config solely so other workspace packages keep resolving; nothing in `apps/docs/src` may reference them.
- `champagne` is a first-class scale (`DEFAULT #CBB079`, `bright #E0CCA0`, `dim #9A825A`, `hairline rgba(203,176,121,.28)`) and `charcoal` supplies `#121212 / #0D0D0D / #0A0A0A`. Separation is drawn with `border-champagne-hairline`, never with a shadow: every `shadow-*` utility has been removed from the deck.
- Telemetry is modal-only. Landing sections carry editorial prose plus three tabular dimensions (Range / Mach / Guests); the oscilloscope, the raw avionics readouts and the audio instrument console exist exclusively inside `CockpitHudModal`, and the canvas plus `AudioTelemetrySynth` are only ever passed to it.
- Geometry is rectilinear on the landing: radii are `rounded-sm` (2px) and the only circles are status dots and the modal reticle. Pills survive inside the cockpit console, which is deliberately styled as an instrument bezel rather than as page furniture.
- Preflight's default border colour is overridden to `#4D4636` in `index.css` so a bare `border` cannot flash cool grey against obsidian, and the App wrapper inks with `text-on-surface` (`#E5E2E1`) instead of pure white.
- **Photography is graded, not just framed.** `HERO_STRATOSPHERE_URL` ships as twilight art graded violet with "digital lilac runway strobe lights" (see its own alt text), so it carried the cyberpunk chroma no class audit could see. `HeroSection` renders it `grayscale brightness-[0.85] contrast-[1.12]` under a `bg-champagne/15 mix-blend-soft-light` layer, which leaves champagne as the deck's only hue. The brightness cut was raised from 0.72 for the "clean lighting, no dimming" brief, and the old top-to-bottom scrim was replaced by a `from-charcoal-black via-charcoal-black/70 to-charcoal-black/10` left-hand wash plus the `.hero-vignette` radial in `index.css` — darkening only the type side keeps the exposed right half of the photograph at mean luma 81.8 instead of crushing the whole frame.
- **#F5D061 and #DFC066 are sanctioned again.** An earlier pass retired them as saturated gamer gold, but the editorial brief names them explicitly as the champagne highlight. They now live as `champagne.gold` / `champagne.brass` in the tone layer (both `apps/docs/tailwind.config.js` and `packages/tokens/src/colors.ts`) and are used for the hero accent clause only. Tailwind emits them as `rgb(245 208 97)`, so grepping built CSS for the literal hex finds nothing — grep the rgb triple.
- **Audio is opt-in, not merely loop-free.** `useAvionicsAudio` boots with `active = false`, so the deck is provably silent: a patched `AudioContext` counter in headless Chromium records 0 constructions on load and 1 only after the operator presses the sound toggle. Tactile click gain is `0.045` on a `0.22` master bus — felt rather than heard. Opening or closing the cockpit no longer chirps; the chirp and datalink burst survive only as explicit buttons inside the cockpit console.
- **The landing nav is four links and one action.** Fleet / Charter / Operations / Concierge, plus icon-only sound and cockpit buttons and the solid `Request Flight` action. `Operations` points at `#operations`, which is `AvionicsTelemetrySuite`'s section id (the old `#avionics` id is gone). No link is marked permanently active, and every `href` on the page resolves — audited as 0 dead anchors.
- The WebGL rig is warm end to end: champagne key `0xcbb079` @1.6, warm ambient `0xffeedb` @1.2, warm-platinum rim `0xe8e2d6` @1.1, graphite fuselage `0x1d1b18`, smoked-warm canopy `0x221e17` at metalness 0.6. A cool rim (`0xdfe3ea` @1.5) or a mirror canopy (metalness 0.92) makes brushed metal read blue even when every token is correct.

### The dominant cause of the "27 failures" was the harness, not the deck

Three measurement defects were producing false readings. They are fixed, and the gate is now trustworthy:

- **`cropToBox` returned the wrong buffer** (`tools/verify-visual/lib/screenshot.cjs`). It correctly built the cropped buffer `out` but returned `data` — the *entire* viewport screenshot — while labelling it with the node's `width`/`height`/`stride`. Every "region" was therefore the top-left corner of the page. This is why contrast reported a worst case of **1:1 alongside a mean of 11:1** on the same node: the crop contained the page's own header text rather than the node's backdrop, so each node was effectively scored against unrelated ink. It single-handedly manufactured ~40 of the 48 reported contrast failures.
- **The ink knockout was photographed before it rendered** (`checks/contrast.cjs`, `checks/scroller.cjs`). `paintInk` sets `color: transparent !important`, but the deck's `transition-colors` means both the computed colour and the painted glyphs lag the inline declaration by its duration. The shutter fired first, so glyphs were still on the plate. Both checks now suppress transitions for the capture, allow two `requestAnimationFrame`s, and then remove the injected tag so the next station's field frame is recorded on the untouched deck.
- **`checks/scroller.cjs` cropped CSS boxes at 1:1** against a frame captured at `deviceScaleFactor` 2, so the Band 3 measurement read the wrong region entirely (and passed at 9.09:1 for the wrong reason). `worstContrast` now takes the session's real ratio. Band 3 measures **7.71:1 / 7.13:1** — still comfortably AA, now actually measured.
- **`checks/style-census.cjs` compared em against px.** `parsePx('0.12em')` yields `0.12`, then `toEm(0.12, 11)` read `0.011em`, so a node wearing `label-caps` (0.12em) reported as drift *against `label-caps` itself* — "wears 0.120em where label-caps define 0.12em".
